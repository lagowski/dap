LangGraph walks the DAG engine

A pipeline is a versioned DAG of agents. Edges and their conditions are data, so the next node is computed, never chosen by a model. Pause, resume, abort, retry, skip.

One node, one adapter node

The node renders its Jinja to XML prompt from pipeline state, hands it to one runtime adapter and writes the result back to state. Live progress for each node.

Gates and history paused

An approval gate interrupts the run until a person approves in the dashboard. Every step, its input and its state diff are stored in SQLite or Postgres.
